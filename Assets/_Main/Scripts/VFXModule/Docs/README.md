# VFXModule

## Назначение

Модуль запускает визуальные эффекты и повторно использует их экземпляры через простой пул.

## Основные части

- `IEffectsService` предоставляет метод `Fire`.
- `EffectsService` берет эффект из очереди или создает новый, запускает его и возвращает в пул после завершения.
- `EffectsCatalog` связывает `EffectId` с prefab.
- `EffectView` оборачивает `ParticleSystem` и сообщает о завершении.
- `VfxServiceInstaller` регистрирует каталог и сервис.

## Подключение

Создайте `EffectsCatalog`, заполните prefab для каждого `EffectId` и укажите контейнер эффектов в `VfxServiceInstaller`.

## Расширение

Новый эффект добавляйте в `EffectId` и каталог. Для эффектов с иным жизненным циклом расширьте контракт view до подключения в пул.
