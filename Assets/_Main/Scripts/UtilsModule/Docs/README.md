# UtilsModule

## Назначение

Модуль содержит компактные технические расширения, которые не принадлежат конкретной игровой области.

## Содержимое

- `DIContainerExtensions.CreateBindAndReturn<T>` создает объект через Zenject, регистрирует тот же экземпляр как singleton и возвращает его.

## Использование

Расширение применяется при динамическом создании зависимостей, например для состояний AI внутри локального `GameObjectContext`.

## Расширение

Добавляйте сюда только универсальные утилиты без доменной логики. Если helper используется одним модулем, оставьте его рядом с владельцем.
