# InputModule

## Назначение

Модуль инкапсулирует Unity Input System и предоставляет игровому коду единый интерфейс ввода.

## Основные части

- `IInputMap` описывает доступные игровые действия и значения осей.
- `IInputService` управляет активацией карт ввода.
- `GameInputService` адаптирует сгенерированный `InputSystem_Actions`.
- `InputInstaller` регистрирует сервис как набор интерфейсов.

## Использование

Контроллеры других модулей должны зависеть от `IInputMap` или `IInputService`, а не читать Unity Input System напрямую.

## Расширение

После изменения input actions обновите сгенерированный `InputSystem_Actions`, затем отразите нужное действие в интерфейсе и адаптере.
