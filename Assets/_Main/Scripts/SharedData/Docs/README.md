# SharedData

## Назначение

Модуль содержит небольшие общие константы, которые нужны нескольким игровым областям и не принадлежат одному владельцу.

## Содержимое

- `EnemyAnimatorHashes` хранит хэши параметров аниматора противника.
- `WeaponAnimatorHashes` хранит хэши параметров аниматора оружия.

## Использование

Используйте готовые хэши вместо повторных строковых вызовов к `Animator`.

## Расширение

Добавляйте сюда только действительно общие данные без поведения. Доменные настройки и сервисы должны оставаться в своих модулях.
