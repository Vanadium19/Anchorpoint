# GameCycleModule

## Назначение

Модуль управляет жизненным циклом игровой сессии: определяет победу или поражение, сохраняет сцену и показывает экран завершения игры.

## Основные части

- `IGameSessionService` и `GameSessionService` отслеживают состояние сессии.
- `GameOverPresenter` связывает завершение с `GameOverView`.
- `GameSceneSaveHandler` подключает сохранение игровой сцены.
- `GameCycleInstaller` регистрирует сервисы и обработчики.

## Интеграция

Сервис опирается на состояние игрока и прогресс базы. UI должен получать изменения через presenter, а сохранение сцены подключается через `SaveModule`.

## Расширение

Дополнительные условия завершения добавляйте в сервис с явным событием или состоянием, не размещая проверку в UI.
