# PlayerModule

## Назначение

Модуль собирает игрового персонажа: перемещение, обзор, приседание, наклоны, взаимодействие с миром, управление оружием и обработку смерти.

## Основные части

- `PlayerInstaller` регистрирует компоненты игрока и сценовые ссылки.
- `PlayerMovementController` передает ввод компонентам движения, вращения, приседания и наклона.
- `WeaponInputController` передает оружию стрельбу, перезарядку, прицеливание и переключение.
- `PlayerInteractionController` ищет добычу и контейнеры перед игроком.
- `InteractionPresenter` показывает подсказки через `InteractionHUDView`.
- `InventoryDeathHandler` переносит инвентарь погибшего игрока в мировую добычу.
- `PlayerProvider` дает другим модулям доступ к объектам игрока.

## Конфигурация

`PlayerConfig` содержит здоровье, движение, камеру и параметры взаимодействия.

## Расширение

Новое управление добавляйте через `InputModule`, затем подключайте в соответствующий контроллер. Переиспользуемую механику сущности выносите в `ComponentsModule`.
