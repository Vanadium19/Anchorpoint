# SpawnModule

## Назначение

Модуль создает противников и стартовую добычу на сцене по настроенным точкам появления.

## Основные части

- `EnemySpawnController` создает волны противников по `SpawnConfig`.
- `EnemyFactory` инстанцирует prefab противника через Zenject: по умолчанию тот, которым его забиндили, либо явно переданный тип.
- `LootSpawnController` создает стартовую добычу.
- `LootFactory` создает одиночные и сложенные мировые предметы.
- `LevelSpawnPointsView` и `LevelLootSpawnPointsView` содержат сценовые точки.
- `SpawnEnemiesAction` создает группу противников по точкам и держит шаг события, пока не убит последний из них.
- `SpawnedEnemy` отвечает, жив ли созданный противник.
- `LootSpawnPointConfig` и `LootEntry` задают таблицу и диапазоны добычи.
- `WorldPlacementService` ищет свободную, стоящую на полу и доступную по NavMesh точку вокруг заданного центра — общий поиск места для всего, что спавнится не по авторским точкам.
- `EventSiteView` помечает префаб площадки события точками охраны, обитателей и лута и её габаритами для проверки свободного места.
- `SpawnEventSiteAction` спавнит площадку события (префаб) с охраной, обитателями и лутом в точке, найденной `WorldPlacementService`.

## Подключение

Добавьте `SpawnInstaller` и `LootSpawnInstaller` на сцену, заполните prefab противника, настройки таймингов и списки точек.

Сцене, которая создает противников только из случайных событий, вместо `SpawnInstaller` нужен `EventSpawnInstaller`: он биндит те же `IEnemyFactory` и `LevelSpawnPointsView`, но без контроллеров волн шутера. Два инсталлера биндят одни и те же типы, поэтому на сцене должен стоять один из них.

## Спавн из случайных событий

`SpawnEnemiesActionAsset` — шаг события: `enemyCount` противников появляются у точек `LevelSpawnPointsView`, начиная со случайной точки и дальше по списку, с разбросом `spawnScatterRadius`. Шаг завершается, когда группа выбита, поэтому «волна» события — это один такой шаг, а пауза между волнами — соседний `DelayActionAsset`. Группы, помеченные `runInParallel`, ждут каждая своих противников.

`SpawnEventSiteActionAsset` — шаг события: спавнит площадку (`sitePrefab`) с охраной и лутом. Площадка — это префаб с охраняющими врагами, обитателями и настраиваемым лутом, точки для которых задаёт его `EventSiteView`; пустые списки точек в `EventSiteView` (или отсутствие компонента на префабе) означают рассыпание группы вокруг центра площадки в её радиусе разброса. Точка ищется так: за начало берётся случайная точка `LevelSpawnPointsView`, если она не подошла — пробуются другие точки этого же уровня; для каждой `WorldPlacementService` ищет вокруг неё, в радиусе `searchRadius`, позицию на полу с приемлемым уклоном, свободную от препятствий по габаритам `EventSiteView` (или дефолтным, если компонента нет), не ближе `minimumPlayerDistance` до точки спавна игрока и достижимую по NavMesh. Если ни одна из точек уровня не дала валидного места, шаг возвращает `false` и ничего не спавнит — событие не тратит кулдаун. После спавна `guardCount` противников появляются через `IEnemyFactory`: из `guardPrefab`, если он задан, иначе из префаба по умолчанию, которым `IEnemyFactory` забиндили на сцене — так площадка бандитов ставит свой тип врага, не заводя отдельного действия. Каждая позиция сначала проецируется на NavMesh, и точка, рядом с которой меша нет, пропускается, чтобы у противника создался агент, — а лут выпадает `Random.Range(minimumLootDrops, maximumLootDrops + 1)` бросками по весам `lootEntries` через `ILootFactory`. Шаг сразу завершается с `true`.

Охрана и обитатели — разные слоты. `guardPrefab`/`guardCount` — враждебные, они ходят, поэтому идут через `IEnemyFactory` и проверку NavMesh. `occupantPrefab`/`occupantCount` — свои, невраждебные персонажи площадки (торговцы и подобные): они инстанцируются контейнером напрямую и встают ровно в точки `EventSiteView.OccupantPoints`, наследуя их поворот, без проверки NavMesh, потому что никуда не идут. Пустой `occupantPrefab` означает площадку без обитателей.

## Расширение

Для новых правил появления расширяйте конфиги и контроллеры, сохраняя фабрики простыми. Данные предметов берите из `InventoryModule`.
