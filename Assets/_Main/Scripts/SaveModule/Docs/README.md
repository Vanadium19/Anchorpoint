# SaveModule

## Назначение

Инфраструктурный модуль сохранений. Он хранит JSON-снимки по ключам и позволяет другим модулям регистрировать собственное сериализуемое состояние.

## Основные части

- `ISaveable` задает `SaveKey`, создание memento и восстановление состояния.
- `IGameSaveLoader` и `GameSaveLoader` регистрируют `ISaveable`, сохраняют, загружают и удаляют слот.
- `IGameRepository` и `GameRepository` выполняют файловые операции.
- `GameSaveData` представляет набор сохраненных значений.
- `AutoSaveHandler` сохраняет данные при завершении контекста.
- `GameSaveLoaderIds` различает игровые сохранения и настройки.

## Использование

Модуль-владелец реализует `ISaveable` и регистрирует его до вызова `Load`. Для выбора слота используйте DI id из `GameSaveLoaderIds`.

## Расширение

Ключ `SaveKey` должен оставаться стабильным между версиями. При изменении формата memento учитывайте обратную совместимость существующих файлов.
