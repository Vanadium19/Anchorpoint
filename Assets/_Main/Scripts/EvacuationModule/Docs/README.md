# EvacuationModule

## Назначение

Модуль управляет эвакуацией из игровой сцены. Он запускает отсчет, отображает состояние эвакуации и завершает сценарий выбранным режимом.

## Основные части

- `IEvacuationService` и `EvacuationService` хранят состояние и прогресс эвакуации.
- `IEvacuationGate` — необязательный запрет на старт эвакуации: пока реализация отвечает `false`, вход в зону не запускает отсчет.
- `EvacuationController` обновляет сценарий во времени.
- `EvacuationPresenter` синхронизирует сервис с `EvacuationView`.
- `EvacuationButton` передает пользовательское действие.
- `EndEvacuationCommand` завершает сценарий асинхронной командой.
- `EvacuationConfig` и `EvacuationCompleteMode` задают параметры завершения.

## Подключение

`EvacuationInstaller` регистрирует сервис, контроллер, presenter и команду. Сценовые ссылки на view и конфиг должны быть заполнены в инспекторе.

## Расширение

Новый вариант завершения добавляйте через `EvacuationCompleteMode` и обработку в команде завершения. Внешний запрет эвакуации подключайте реализацией `IEvacuationGate` в инсталлере своей сцены — без биндинга эвакуация всегда разрешена.
