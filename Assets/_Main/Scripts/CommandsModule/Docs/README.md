# CommandsModule

## Назначение

Небольшой инфраструктурный модуль для асинхронных команд UI. Он задает единый контракт выполнения и базовые компоненты кнопок.

## Основные части

- `IAsyncCommand` и обобщенные варианты до пяти аргументов возвращают `UniTask<TaskResult>`.
- `TaskResult` описывает результат выполнения: успех, ошибка, выполнение, прерывание или отсутствие запуска.
- `ExecuteCommandButton` связывает Unity `Button` с командой, полученной через Zenject.

## Использование

Реализуйте подходящий `IAsyncCommand`, зарегистрируйте его в контейнере и создайте компонент-наследник нужного `ExecuteCommandButton`.

## Расширение

Команда содержит сценарий, а кнопка только передает ввод. Не помещайте бизнес-логику в наследники `ExecuteCommandButton`.
