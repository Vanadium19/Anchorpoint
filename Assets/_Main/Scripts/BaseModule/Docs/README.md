# BaseModule

## Назначение

Модуль отвечает за развитие базы: накопление очков, расчет уровня, достижение победного уровня и визуальное превью награды от постройки. Здесь же находится базовый контейнер-сундук.

## Основные части

- `IBaseLevelService` и `BaseLevelService` хранят очки базы, вычисляют уровень и публикуют события изменений.
- `BaseLevelPreview` описывает результат предварительного добавления очков.
- `BaseLevelPresenter` и `BaseLevelView` показывают прогресс и анимируют превью.
- `ChestContainer` предоставляет инвентарю контейнер базы через `IContainerUI`.
- `BaseModuleInstaller` регистрирует конфиг и сервис.

## Конфигурация

`BaseLevelConfig` содержит пороги уровней и целевой уровень победы. `BaseLevelUIConfig` задает текстовые форматы и параметры анимации интерфейса.

## Расширение

Игровой код должен зависеть от `IBaseLevelService`. Для предварительного отображения награды используйте `GetPreview`, а фактическое начисление проводите через `AddPoints`.
