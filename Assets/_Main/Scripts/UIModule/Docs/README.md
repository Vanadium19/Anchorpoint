# UIModule

## Назначение

Модуль содержит общие игровые HUD-компоненты: здоровье, подсказки взаимодействия и активные баффы.

## Основные части

- `HealthPresenter` подписывается на `IHealthComponent` и обновляет `HealthView`.
- `InteractionHUDView` показывает и скрывает текстовую подсказку.
- `BuffsView` подписывается на `IBuffService` и создает `BuffSlotView` для активных эффектов.
- `BuffSlotView` отображает иконку и оставшееся время.

## Использование

HUD-view передаются через сценовые ссылки или внедрение зависимостей. UI должен получать состояние через presenter или события сервисов.

## Расширение

Новый HUD-блок оформляйте отдельными view и presenter. Не размещайте игровую логику в MonoBehaviour представления.
