# EnemyModule

## Назначение

Модуль описывает противника: здоровье, навигацию, обзор, стрельбу, AI-состояния, ragdoll и выпадение добычи.

## Основные части

- `EnemyInstaller` собирает компоненты сущности внутри `GameObjectContext`.
- `AIAgent` запускает FSM из сериализованного `AutoStateMachineAsset`.
- Состояния `PatrolState`, `ChaseState`, `AttackState` и `ReloadState` реализуют поведение AI по игроку.
- `AttackStructureState` ведет противника к ближайшей постройке и расстреливает ее, пока не увидит игрока.
- `Blackboard` хранит данные между состояниями, сейчас в том числе последнюю позицию цели.
- `EnemyConfig` задает здоровье, навигацию, восприятие, бой, патруль и таблицу добычи.
- `EnemyView` обновляет анимацию и включает `EnemyRagdoll` после смерти.
- `LootDumper` создает мировые предметы после смерти.

## FSM

Переходы оформлены отдельными классами и создаются через Zenject-адаптеры. Общая реализация конечного автомата находится в `FSMModule`.

## Типы противников

Тип противника — это пара «префаб + `EnemyConfig`»: префаб держит модель, материалы и ссылку на конфиг в своем `EnemyInstaller`, конфиг задает здоровье, восприятие, бой и таблицу добычи. Поведение у всех типов общее, поэтому новый тип не требует кода: `Bandit` — вариант базового префаба со своим материалом и `BanditConfig`, у которого собственные `maxDropItems` и `loot`. Кто из типов появится в конкретном месте, решает тот, кто вызывает `IEnemyFactory`.

## Расширение

Новое состояние требует класса состояния, asset-обертки, переходов и регистрации зависимостей в контексте противника. Новый тип противника — только префаб и `EnemyConfig`.

## Цели-постройки

`IStructureTargetSource` и `IStructureTarget` из `ComponentsModule` — узкий контракт для целей, которые не являются игроком. Реализация живет в модуле-владельце построек, поэтому `EnemyModule` о нем не знает. Зависимость необязательна: на сцене без биндинга `AttackStructureState` целей не находит, и AI работает только по игроку. Состояние перемещается к цели, останавливается на `StructureAttackRange` от границ постройки и расстреливает её своим оружием, перезаряжаясь на месте при пустом магазине; урон за выстрел — `StructureDamage`, темп стрельбы — `StructureAttackRate`.
