# EnemyModule

## Назначение

Модуль описывает противника: здоровье, навигацию, обзор, стрельбу, AI-состояния, ragdoll и выпадение добычи.

## Основные части

- `EnemyInstaller` собирает компоненты сущности внутри `GameObjectContext`.
- `AIAgent` запускает FSM из сериализованного `AutoStateMachineAsset`.
- Состояния `PatrolState`, `ChaseState`, `AttackState` и `ReloadState` реализуют поведение AI.
- `Blackboard` хранит данные между состояниями, сейчас в том числе последнюю позицию цели.
- `EnemyConfig` задает здоровье, навигацию, восприятие, бой, патруль и таблицу добычи.
- `EnemyView` обновляет анимацию и включает `EnemyRagdoll` после смерти.
- `LootDumper` создает мировые предметы после смерти.

## FSM

Переходы оформлены отдельными классами и создаются через Zenject-адаптеры. Общая реализация конечного автомата находится в `FSMModule`.

## Расширение

Новое состояние требует класса состояния, asset-обертки, переходов и регистрации зависимостей в контексте противника.
