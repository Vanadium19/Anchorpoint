# EffectModule

## Назначение

Модуль отвечает за применение предметных эффектов и временных баффов. Он связывает данные предметов с изменениями здоровья, боезапаса и характеристик сущности.

## Основные части

- `IEffect`, `IBuff` и `BuffBase` задают контракты эффектов и баффов.
- `BuffService` хранит активные баффы, обновляет их и публикует события для UI.
- `PrimaryBuffTargetService` определяет основную сущность-получателя баффов.
- `ItemUseHandler` применяет эффекты используемых предметов.
- `BuffCatalog` и наследники `EffectDataSo` описывают эффекты в данных.
- `BuffSaveable` сохраняет активные баффы.

## Подключение

`EffectInstaller` регистрирует каталог, сервисы, обработчик использования предметов и сохранение баффов.

## Расширение

Новый эффект добавляйте как новый тип данных и соответствующую реализацию. Для сохраняемого баффа обновляйте каталог и восстановление memento.
