# FSMModule

## Назначение

Общий модуль конечных автоматов. Он не знает о конкретных игровых сущностях и используется для описания состояний и переходов через сериализуемые assets.

## Основные части

- `IState`, `BaseState`, `CompositeState` и `DecoratorState` задают поведение состояния.
- `IStateTransition` и `AbstractStateTransition` описывают переход между именованными состояниями.
- `StateMachine` выполняет текущий state и проверяет переходы.
- `AutoStateMachine` строит автомат из asset-описания.
- `IStateAsset`, `IStateTransitionAsset` и `StateMachineAsset` позволяют задавать автомат данными Unity.

## Использование

Модуль-владелец определяет enum имен состояний, конкретные реализации и asset-фабрики. Пример полной интеграции находится в `EnemyModule/AIModule`.

## Расширение

Сохраняйте FSM независимым от Zenject и игровых доменов. Адаптацию к контейнеру выполняйте в модуле-потребителе.
