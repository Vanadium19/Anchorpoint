# CampSaveModule

## Назначение

Модуль собирает сохранение лагеря в единый сценарий. Он сохраняет очки базы, размещенные постройки, инвентарь и активные эффекты при работе на сцене лагеря.

## Основные части

- `CampSaveable` сериализует `CampMemento` и восстанавливает базу и постройки.
- `CampSaveHandler` регистрирует лагерные `ISaveable`, запускает загрузку и снимает регистрации при уничтожении контекста.
- `CampSceneInstaller` подключает сценового игрока, инвентарь и обработчик сохранения.

## Жизненный цикл

При инициализации `CampSaveHandler` регистрирует `CampSaveable`, `InventorySaveable` и `BuffSaveable`, затем вызывает загрузку игрового слота. При завершении сцены регистрации удаляются.

## Расширение

Новое сохраняемое состояние лагеря добавляйте в `CampMemento`, `CampSaveable` и, если это отдельный `ISaveable`, в регистрацию `CampSaveHandler`.
